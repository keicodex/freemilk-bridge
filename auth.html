FreeMilk sign-in for freemilk-bridge

Sign in with the Google account you use for FreeMilk. The page will show a Firebase ID token and refresh token. Hand both to the bridge once (login_fetch.py set-tokens); the refresh token lets the bridge renew the ID token by itself afterwards.

Treat the refresh token like a password: whoever holds it can mint ID tokens for this FreeMilk account until you sign out / revoke sessions. It is stored only in the bridge's 0600 credentials file.
